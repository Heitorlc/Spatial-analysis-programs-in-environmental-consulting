# Spatial-analysis-programs-in-environmental-consulting
The following programs were developed to automate processes within environmental consulting in order to streamline internal workflows.

The first one I created was for morphometric analysis of watersheds, which allows for the creation of watershed boundaries, main and secondary drainage systems, calculations, and morphometric analysis of the terrain. The data can be easily exported in a short time.

The second program involves the automatic analysis of overlaps of the project to be licensed in the state of Minas Gerais, Brazil, with socio-environmental spatial data coming directly from the WFS IDE-SISEMA. As its use is restricted to the licensing process in Brazil and the state of Minas Gerais, the script is entirely in Portuguese to facilitate its use by users.

The third program created is similar to the second, but for the automatic calculation of forest inventories in the environmental intervention process in Environmental Intervention Projects in the state of Minas Gerais. It has three modules: 1) 100% Census; 2) Simplified Sampling; 3) Stratigraphic Sampling. Furthermore, if the intervention area is corrective, the program extrapolates from the control area to the corrective area. Additionally, the trees are geolocated using coordinates and can be exported as .shp or .kml files with calculations for each tree.
